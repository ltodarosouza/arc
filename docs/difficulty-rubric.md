# Arc — rubric manual de dificuldade

## Objetivo

Dificuldade descreve o esforço acadêmico esperado para resolver uma questão corretamente **sem ajuda**, no contexto do assunto marcado. Não mede valor pedagógico, extensão do enunciado ou qualidade da questão.

A classificação inicial é editorial. Dados de uso futuro ajudam a revisá-la, mas não alteram a etiqueta automaticamente.

## Critérios de decisão

Classifique a questão considerando, nesta ordem:

1. **Reconhecimento do método** — o procedimento está explicitamente indicado ou precisa ser escolhido?
2. **Raciocínio necessário** — basta uma aplicação direta ou há decisões/interpretações relevantes?
3. **Quantidade de passos conceituais** — os passos são uma rotina conhecida ou exigem combinar ideias?
4. **Erros plausíveis** — os distratores representam deslizes comuns sem transformar a questão em uma pegadinha?

O tamanho de uma conta não torna uma questão difícil por si só. Um enunciado confuso não deve receber dificuldade maior: deve ser reescrito ou rejeitado.

## Níveis para Cálculo II

### Fácil

Aplicação direta de uma definição, fórmula ou método já indicado pelo formato do exercício. Há pouca escolha estratégica e uma única ideia central.

Exemplos:

- calcular uma antiderivada por regra imediata;
- identificar a soma de uma série geométrica com razão explícita;
- fazer uma substituição quando a derivada interna aparece exatamente no integrando.

### Média

Exige reconhecer o método adequado ou encadear poucos passos conhecidos. Os distratores devem refletir uma escolha de método inadequada ou erro de execução frequente.

Exemplos:

- decidir entre substituição e integração por partes;
- verificar a condição de convergência e então calcular uma soma;
- aplicar um teste de convergência com álgebra intermediária curta.

### Difícil

Exige estratégia, combinação de conceitos, interpretação de condições ou análise de casos. A dificuldade vem do raciocínio, não de aritmética excessiva.

Exemplos:

- escolher e justificar entre testes de comparação, razão ou raiz;
- determinar intervalo de convergência com análise dos extremos;
- resolver uma integral imprópria que exige decomposição em casos e interpretação de convergência.

## Processo de revisão

1. O autor propõe a dificuldade usando esta rubrica.
2. A revisão pedagógica confirma ou altera a etiqueta e registra uma justificativa curta quando houver dúvida.
3. Cada tópico lançado deve ter cobertura nas dificuldades que fizerem sentido; não forçar questões difíceis onde o conteúdo não comporta isso.

## Recalibração com uso real

Depois de haver volume suficiente de respostas agregadas e preservando a privacidade dos estudantes, a curadoria compara a etiqueta editorial com:

- taxa de acerto por questão;
- distribuição das alternativas escolhidas;
- padrões de erro recorrentes;
- diferença de desempenho entre tópicos e turmas, quando houver contexto suficiente.

Os dados servem para abrir uma revisão editorial. Eles não devem mudar a dificuldade automaticamente, pois baixa taxa de acerto também pode indicar enunciado ambíguo, distrator ruim ou pré-requisito mal classificado.
