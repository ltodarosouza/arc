# Cálculo II — launch content map

## Role of this map

This is Arc’s first **validation slice**, not a claim that every university teaches the same Cálculo II course. It deliberately focuses on the content that gives the product enough depth to test topic navigation, difficulty filters, solutions, and progress.

The initial launch goal is **at least 109 reviewed questions**. Every published question needs a correct taxonomy tag, difficulty, origin record, final answer, and commented solution.

## Difficulty distribution

Each topic should aim for roughly:

- 35–40% easy: direct application after learning the method;
- 40–45% medium: requires method selection or a small combination of steps;
- 20–25% hard: combines ideas, includes traps, or requires deeper interpretation.

This is an initial editorial target, not a replacement for later difficulty calibration from learner attempts.

## Pedagogical order

1. Start with antiderivatives and definite integrals.
2. Progress through integration techniques.
3. Introduce improper integrals once ordinary integral reasoning is stable.
4. Move to sequence limits and convergence.
5. Finish with increasingly sophisticated convergence tests, power series, and Taylor series.

The interface may still let a learner jump directly to any topic. The order guides discovery, content production, and suggested practice; it does not impose a study plan.

## Known gaps, intentionally deferred

These topics can appear in Cálculo II elsewhere, but are not part of this first validation slice:

- parametric and polar curves;
- differential equations;
- multivariable calculus;
- vector calculus;
- numerical integration and error analysis beyond the selected series content.

If a local curriculum needs one of these, Arc should add it as a new taxonomy branch rather than relabeling an unrelated topic.

## Editorial release gate

A topic is not considered launched merely because questions exist. It needs:

1. its minimum coverage count;
2. at least one reviewed question at each available difficulty;
3. verified final answers and readable commented solutions;
4. correct primary and secondary taxonomy tags;
5. provenance recorded for every question.
